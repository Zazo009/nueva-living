# Nueva Living — German review notes

Please **revise** the existing translation: grammar, idiom, register and flow.

The terms below are deliberate and settled across ~980 pages. If you believe one is
wrong, say so in the `note` column — please do not silently change it, because each
one is enforced by an automated check and a lone edit will be reverted.

## Conventions

- **Form of address:** Sie — one form throughout, including tables and buttons.
- **Quarters:** `Q4` (fourth quarter).
- **Area unit:** `m²`   **Decimal mark:** `, (comma)`
- **Prices:** the € symbol, never "EUR"; keep this locale's separator and symbol position.
- **Sentence case** for headings, not English Title Case (German capitalises nouns as normal).
- **Company descriptor:** Private Neubau-Beratung an der Costa del Sol

## Two deliberate exceptions

1. **"Completion" in a payment-schedule row** is translated as the *notarial deed*
   (Spanish: Escritura), because the milestone is the deed signing. That is correct there
   and differs from "Completion" elsewhere.
2. **Built area is not living area.** The figure comes from the developer's
   *superficie construida* — built, walls included. Please keep it distinct from the
   usable/interior figure, which is a separate, smaller number with its own label.
